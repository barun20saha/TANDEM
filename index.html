First-Run & Install Guides

Linux (Stage A)

AppImage: chmod +x tandem-*.AppImage && ./tandem-*.AppImage

Debian/Ubuntu: sudo apt install ./tandem_*_linux_amd64.deb

Firewall (ufw): sudo ufw allow Tandem (or ports 22000/tcp, 22000/udp, 21027/udp).

Windows (Stage B)

Run tandem-*-windows-amd64-setup.exe. If unsigned, SmartScreen shows Windows protected your PC → click More info → Run anyway after checking SHA-256.

The installer adds Windows Defender Firewall rules bound to tandemd.exe.

macOS (Stage B)

Drag Tandem.app to Applications. If unsigned/unnotarized, right-click → Open on first launch (or allow in System Settings → Privacy & Security).

Grant Local Network access when prompted so LAN discovery works.

Android (Stage C)

New signed APKs may trigger Play Protect's "Scan app" prompt — tap Scan app.

Verify the APK signing certificate SHA-256 with apksigner verify --print-certs tandem-*.apk against the release notes.

Troubleshooting & Checksum Verification

Symptom Cause Fix
Verify Download Checksum Confirm artifact integrity before running Linux/macOS: sha256sum -c SHA256SUMS.txt · Windows: Get-FileHash tandem-*.exe -Algorithm SHA256
Firewall blocking peers Inbound TCP/UDP 22000 or UDP 21027 blocked Linux: sudo ufw allow 22000/tcp && sudo ufw allow 22000/udp && sudo ufw allow 21027/udp; Windows: re-run install-firewall.ps1 as Admin.
macOS can't see LAN devices Local Network permission denied Open System Settings → Privacy & Security → Local Network and enable Tandem.
Same Wi-Fi, devices don't appear Guest/campus router client (AP) isolation Turn on a phone hotspot (mobile data can stay off), connect your laptop to it, and transfer directly.
